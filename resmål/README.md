## Konvention

- Ett resmål = en fil här i mappen (`<slug>.md`)
- Nya tips under resesnack sparas automatiskt: befintligt resmål → uppdatera den filen, nytt resmål → ny fil + rad i tabellen ovan
- Se `AGENTS.md` → "✈️ Resetips" för hela rutinen
